# Internal engineering records

This directory holds engineering records kept for auditability: release-readiness
reviews, benchmark snapshots, and similar evidence gathered at a specific point
in time on specific hardware.

These are not user documentation. They describe one measurement or one review,
against the commit and machine named inside them, and they are not maintained as
the code moves on. Read them as history, not as current behavior or as a
performance promise.

For current behavior, use the user documentation in [`../`](../), starting with
[`observability.md`](../observability.md).
